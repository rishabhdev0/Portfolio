## 👨‍💻 About This Portfolio

**Rishabh Portfolio** is my personal developer portfolio, designed to showcase:

- 🚀 Featured projects
- 🧠 Technical skills
- 🎓 Education
- 📬 Contact information
- 📊 GitHub activity
- 🎨 My visual style as a developer

The goal of this portfolio is simple: make the work easy to understand, make the design memorable, and keep the codebase maintainable for future updates.

---

## ✨ Key Features

- 🎨 **Neo-brutalist design** with bold borders, strong shadows, and expressive colors
- 📱 **Responsive layout** for mobile, tablet, and desktop
- ⚛️ **React component architecture** for clean maintainability
- 🎞️ **Framer Motion animations** for smooth section reveals and interactions
- 🖱️ **Custom cursor** on desktop
- 🧩 **Project cards** with screenshots, tags, demo links, and GitHub links
- 🛠️ **Skills section** grouped by category
- 📊 **GitHub contribution calendar**
- 📬 **Contact form** powered by Web3Forms
- 📈 **Vercel Analytics** integration

⚙️ Local Development
1. Clone the Repository
git clone https://github.com/rishabhdev0/Portfolio.git
cd Portfolio
2. Install Dependencies
npm install
3. Start Development Server
npm run dev
4. Build for Production
npm run build
5. Preview Production Build
npm run preview
🧩 Maintenance Guide
➕ Add a Project
Edit:

src/components/ProjectSection.jsx
Add a new project object:

{
  id: 6,
  title: "Project Name",
  description: "Short project description.",
  image: projectImage,
  tags: ["React.js", "API", "Dashboard"],
  demoUrl: "https://example.com",
  githubUrl: "https://github.com/username/repo",
}
➕ Add a Skill
Edit:

src/components/SkillsSection.jsx
Add:

{
  name: "New Skill",
  image: "/skills/new-skill.svg",
  category: "frameworks"
}
