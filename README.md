# Rishabh Portfolio

![Rishabh Portfolio Preview](./public/og-image.png)

A bold, animated, neo-brutalist developer portfolio built for showcasing my projects, skills, education, and contact details in one clean place. The portfolio is designed to feel modern, personal, responsive, and easy to maintain.

## ✨ Features

- 🎨 Neo-brutalist design with bold borders, shadows, and bright colors
- ⚡ Built with React and Vite for fast development
- 📱 Fully responsive layout for desktop, tablet, and mobile
- 🧑‍💻 Project showcase with live/demo and GitHub links
- 🛠️ Categorized skills section with technology icons
- 🎓 Education section
- 📬 Contact form integration
- 📊 GitHub contribution calendar
- 🖱️ Custom animated cursor
- 📈 Vercel Analytics support

⚙️ Installation
Clone the repository:

git clone https://github.com/rishabhdev0/Portfolio.git
cd Portfolio
Install dependencies:

npm install
Start the development server:

npm run dev
Build for production:

npm run build
Preview production build:

npm run preview
🖼️ Important Assets
The main images used in this portfolio are stored in:

src/assets/
Important files:

profilePicture.jpeg

Skill icons are stored in:

public/skills/
Example usage:

"/skills/react.svg"
✏️ Updating Projects
Projects are managed inside:

src/components/ProjectSection.jsx
Each project uses this structure:

{
  id: 1,
  title: "Project Name",
  description: "Project description",
  image: projectImage,
  tags: ["React.js", "API", "Dashboard"],
  demoUrl: "https://example.com",
  githubUrl: "https://github.com/username/repo",
}
✏️ Updating Skills
Skills are managed inside:

src/components/SkillsSection.jsx
Example:

{
  name: "React.js",
  image: "/skills/react.svg",
  category: "frameworks"
}
